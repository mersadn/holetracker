# مدیریت سوراخ‌ها (Hole Tracker)

یک وب‌اپ ساده و زیبا برای ثبت «نام مشتری» و «شماره سوراخ». اطلاعات روی سرور محلی شما در یک فایل (`data.json`) ذخیره می‌شود، پس با رفرش کردن صفحه یا حتی خاموش/روشن کردن سیستم پاک نمی‌شود.

## اجرا روی سیستم خودتان

پیش‌نیاز: نصب بودن [Node.js](https://nodejs.org) (نسخه ۱۶ به بالا)

```bash
# ۱. وارد پوشه پروژه شوید
cd hole-tracker

# ۲. پکیج‌ها را نصب کنید
npm install

# ۳. سرور را اجرا کنید
npm start
```

سپس در مرورگر بروید به:
```
http://localhost:3000
```

## آپلود روی گیت‌هاب

```bash
git init
git add .
git commit -m "اولین نسخه - اپ مدیریت سوراخ‌ها"
git branch -M main
git remote add origin <لینک ریپازیتوری شما>
git push -u origin main
```

فایل `data.json` (دیتابیس) در `.gitignore` قرار داده شده تا اطلاعات مشتری‌های شما به‌صورت پیش‌فرض روی گیت‌هاب آپلود نشود و در سیستم محلی خودتان بماند. اگر می‌خواهید همراه پروژه روی گیت‌هاب هم باشد، خط مربوطه را از `.gitignore` حذف کنید.

## ساختار پروژه

```
hole-tracker/
├── server.js        ← سرور Express + API
├── package.json
├── data.json         ← دیتابیس (به‌صورت خودکار ساخته می‌شود)
├── public/
│   ├── index.html    ← رابط کاربری
│   └── app.js         ← منطق فرانت‌اند
└── README.md
```
