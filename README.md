# مدیریت سوراخ‌های DTF

یک اپلیکیشن وب (PWA) برای ثبت و پیگیری قرارگیری رول‌های DTF داخل سوراخ‌های دستگاه.
قابل نصب روی سیستم (ویندوز/مک/لینوکس) به‌صورت یک برنامهٔ مستقل، بدون نیاز به اینترنت پس از اولین اجرا.

## ویژگی‌ها

- نقشهٔ تصویری سوراخ‌ها (شماره‌های ۱۴ تا ۶۷) — سوراخ خالی **سبز**، سوراخ پر **قرمز**.
- فرم افزودن رکورد جدید: نام مشتری + انتخاب شماره سوراخ (یا کلیک مستقیم روی سوراخ آزاد در نقشه) + توضیحات اختیاری.
- لیست کامل رکوردهای ثبت‌شده با وضعیت «در انتظار» / «تحویل شده».
- با کلیک روی برچسب شماره سوراخ در لیست، رکورد «تحویل شده» می‌شود و سوراخ دوباره آزاد (سبز) می‌شود؛ با کلیک دوباره به حالت «در انتظار» برمی‌گردد.
- جستجوی زنده بر اساس نام مشتری یا شماره سوراخ، با پیشنهاد خودکار (Autocomplete) و سفید شدن سوراخ مورد نظر روی نقشه.
- خروجی/ورودی دیتابیس: گرفتن نسخهٔ پشتیبان از تمام اطلاعات به‌صورت یک فایل JSON و بازیابی آن روی هر سیستم دیگر.
- کاملاً آفلاین کار می‌کند (بعد از اولین بار باز شدن) و قابل نصب روی دسکتاپ.

## نصب و اجرا (اولین بار)

برنامه یک وب‌اپ است و برای نصب باید یک‌بار از طریق مرورگر (Chrome یا Edge) باز شود:

1. پوشهٔ برنامه را در هر مسیری از سیستم قرار دهید.
2. **ویندوز:** روی فایل `start.bat` دوبار کلیک کنید.
   **مک/لینوکس:** فایل `start.sh` را اجرا کنید (`./start.sh` در ترمینال).
   - این اسکریپت‌ها از پایتون (که معمولاً از قبل روی سیستم نصب است) برای اجرای یک سرور محلی کوچک استفاده می‌کنند و مرورگر را به‌صورت خودکار باز می‌کنند.
   - اگر پیام «پایتون پیدا نشد» دیدید، یک‌بار Python را از python.org نصب کنید (رایگان، ۲ دقیقه) و دوباره فایل را اجرا کنید.
3. صفحه در مرورگر باز می‌شود. در نوار آدرس مرورگر (Chrome/Edge) آیکون نصب (⊕ یا «Install app») را بزنید، یا از دکمهٔ **«نصب برنامه روی سیستم»** در گوشهٔ بالای صفحه استفاده کنید.
4. برنامه به‌صورت یک آیکون مستقل روی دسکتاپ/منوی استارت نصب می‌شود و از این پس مثل یک نرم‌افزار عادی (بدون نوار آدرس مرورگر) باز می‌شود.
5. از این به بعد، هر بار برای اجرا کافی است دوباره `start.bat` (یا `start.sh`) را اجرا کنید و سپس آیکون نصب‌شدهٔ برنامه را باز کنید. (سرور محلی فقط برای بارگذاری اولیهٔ هر بار لازم است.)

> نکته: چون این سرور محلی روی خود سیستم اجرا می‌شود، برنامه فقط روی همان کامپیوتر در دسترس است — دقیقاً همان‌طور که خواسته بودید.

## ذخیره‌سازی اطلاعات

تمام رکوردها در حافظهٔ محلی همان مرورگر/سیستم ذخیره می‌شوند و با بستن یا ری‌استارت سیستم از بین نمی‌روند.
برای پشتیبان‌گیری یا انتقال اطلاعات به سیستم دیگر:

- **خروجی دیتابیس:** یک فایل `dtf-database-...json` شامل همهٔ رکوردها دانلود می‌شود.
- **ورودی دیتابیس:** همان فایل JSON را انتخاب کنید تا اطلاعات بازیابی شود (اطلاعات فعلی جایگزین می‌شود، پس قبل از آن یک خروجی از وضعیت فعلی بگیرید).

## ساختار فایل‌ها

```
index.html          صفحهٔ اصلی برنامه
style.css           استایل و طراحی
app.js              منطق برنامه (نقشهٔ سوراخ‌ها، لیست، جستجو، دیتابیس)
manifest.json        تنظیمات نصب PWA
service-worker.js    کش کردن فایل‌ها برای کارکرد آفلاین
icons/               آیکون‌های برنامه
start.bat / start.sh اجرای سریع سرور محلی
```
