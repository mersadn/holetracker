# مدیریت سوراخ‌ها (Hole Tracker)

یک وب‌اپ ساده و زیبا برای ثبت «نام مشتری» و «شماره سوراخ» (بازه ۱۴ تا ۶۷). اطلاعات در فایل `data.json` ذخیره می‌شود و **همراه پروژه روی گیت‌هاب قرار می‌گیرد** تا با هر سیستمی که ریپازیتوری را کلون/پول کند، همان داده‌ها در دسترس باشد.

## اجرا روی سیستم خودتان

پیش‌نیاز: نصب بودن [Node.js](https://nodejs.org) (نسخه ۱۶ به بالا)

```bash
# ۱. وارد پوشه پروژه شوید
cd hole-tracker

# ۲. پکیج‌ها را نصب کنید
npm install

# ۳. سرور را اجرا کنید
npm start
```

سپس در مرورگر بروید به:
```
http://localhost:3000
```

## دیتابیس مشترک روی گیت‌هاب

برخلاف نسخه قبلی، فایل `data.json` دیگر در `.gitignore` نیست؛ یعنی با هر `git add` و `commit`، داده‌های شما هم روی گیت‌هاب ذخیره می‌شوند.

**نکته مهم:** این یک همگام‌سازی زنده (real-time) نیست. برای اینکه هر سیستم آخرین داده‌ها را ببیند، باید:

```bash
# روی سیستمی که داده جدید وارد کرده‌اید
git add data.json
git commit -m "به‌روزرسانی رکوردها"
git push

# روی سیستم دیگر، قبل از اجرا
git pull
npm start
```

اگر همزمان از دو سیستم مختلف ویرایش کنید، همیشه قبل از شروع کار `git pull` بزنید تا دچار تداخل (conflict) نشوید.

فایل `data.json` همراه این تحویل، **خالی و ریست‌شده** است (رکوردهای آزمایشی قبلی حذف شدند) تا رکوردهای واقعی خودتان را از نو وارد کنید.

## آپلود روی گیت‌هاب

```bash
git init
git add .
git commit -m "اولین نسخه - اپ مدیریت سوراخ‌ها"
git branch -M main
git remote add origin <لینک ریپازیتوری شما>
git push -u origin main
```

## ساختار پروژه

```
hole-tracker/
├── server.js         ← سرور Express + API
├── package.json
├── data.json          ← دیتابیس (روی گیت‌هاب هم آپلود می‌شود)
├── .gitignore
├── public/
│   ├── index.html     ← رابط کاربری (نسخه دسکتاپ، بدون اسکرول صفحه)
│   └── app.js          ← منطق فرانت‌اند
└── README.md
```

## امکانات

- طراحی اختصاصی دسکتاپ: فرم افزودن و لیست مشتریان **کنار هم**، بدون اسکرول کل صفحه (فقط خود جدول در صورت طولانی بودن، اسکرول داخلی دارد)
- شماره سوراخ به‌صورت **انتخاب از لیست ۱۴ تا ۶۷** (نه ورودی آزاد) — سوراخ‌های در حال استفاده به‌طور خودکار غیرفعال می‌شوند
- کلیک روی برچسب شماره سوراخِ هر مشتری → علامت‌گذاری «تحویل داده شد» (و با کلیک دوباره، برگشت به «در انتظار» و آزاد شدن دوباره‌ی سوراخ)
- فیلتر سریع بین همه / در انتظار / تحویل‌شده + شمارنده‌های آماری بالای صفحه
- جستجوی آنی بین رکوردها
- ذخیره‌سازی پایدار روی دیسک و به‌اشتراک‌گذاری از طریق گیت‌هاب
- طراحی مدرن و شیشه‌ای (Glassmorphism) و راست‌چین برای فارسی
